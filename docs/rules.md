# Veridyn – Smart Rules Engine (Initial)

## Rule 1: Weak Topic Detection
If a topic is skipped more than once → mark as weak

## Rule 2: Risk Detection
If remaining topics > remaining days → RED status

## Rule 3: On-Track Detection
If completion rate >= 80% → GREEN status

## Rule 4: Adaptive Planning
If a day is missed:
- redistribute tasks
- increase next day load slightly
