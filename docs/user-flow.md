# Veridyn – User Flow

## 1. Landing Page
- Student sees what Veridyn does
- Clicks "Get Started"

## 2. Student Setup
Student enters:
- Name
- Exam name
- Exam date
- Daily available study hours

## 3. Subject & Syllabus Setup
For each subject:
- Subject name
- Topics (list)
- Difficulty level (Easy / Medium / Hard)

## 4. Plan Generation
System calculates:
- Days remaining
- Topics per day
- Daily study plan

## 5. Daily Dashboard
Shows:
- Today's tasks
- Time required
- Completion status

Student can:
- Mark task as done
- Skip task (with reason)

## 6. Progress Tracking
System tracks:
- Completion %
- Missed tasks
- Weak subjects

## 7. Readiness Indicator
Color-based status:
- Green → On track
- Yellow → Falling behind
- Red → High risk
