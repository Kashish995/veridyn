# Veridyn

Veridyn is a smart education planning and guidance platform designed to help students prepare for exams systematically instead of relying on last-minute studying.

## Problem
Students often struggle with exam preparation due to lack of structured planning, unclear priorities, and poor tracking of progress and weak areas.

## Solution
Veridyn converts syllabus, exam timelines, and student performance data into:
- daily and weekly study goals
- progress indicators
- early warnings for weak subjects

## Core Features
- Student profile with subjects and exam dates
- Smart study plan generation
- Daily task tracking
- Progress and readiness dashboard
- Rule-based weak area detection

## Tech Stack
- Frontend: React
- Backend: Node.js + Express
- Database: MongoDB

## Status
Initial setup completed. Core planning logic under development.
