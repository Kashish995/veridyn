# Veridyn – Full Stack Task Management System

Veridyn is a full-stack task management application built using React, Node.js, Express, and MongoDB.  
It allows users to manage tasks with a clean UI and real-time backend integration.

---

## 🚀 Features
- Create tasks
- View tasks by user
- Update task status (pending / completed)
- Delete tasks
- Clean dark UI
- REST API based backend
- Proper CORS handling

---

## 🛠 Tech Stack

### Frontend
- React (Vite)
- JavaScript
- CSS

### Backend
- Node.js
- Express.js
- MongoDB
- Mongoose
